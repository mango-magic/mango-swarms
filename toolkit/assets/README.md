# Visual assets.

The Swarms hero uses MangoMagic's supplied 2026 brand assets and house palette:
Cream `#F6F0E2`, Navy `#111527` and Mango Gold `#F1AB1C`.

- `mangomagic-mark.svg`: original gold mark from the MangoMagic 3.0 logo library.
- `mangomagic-wordmark.svg`: original wide, reversed wordmark from the same library.
- `banner.svg`: desktop composition with that authentic mark and wordmark.
- `banner-mobile.svg`: portrait composition for narrow screens.

The two standalone logo files retain the supplied vector geometry. The hero
compositions embed those vectors without external requests. Playfair Display
Regular/Italic and Montserrat Bold lettering is outlined so GitHub does not need
to load custom fonts. No font binaries are distributed. Both typefaces are
licensed under the SIL Open Font License; see
[Playfair Display](https://github.com/clauseggers/Playfair-Display) and
[Montserrat](https://github.com/JulietaUla/Montserrat).

The banners use opaque brand colours so they remain legible in light and dark
GitHub themes. The README uses standard Markdown and a responsive `picture`
element, without scripts or custom page CSS. GitHub controls the surrounding
page typography and theme. Descriptive image alt text and SVG titles retain the
hero's meaning for readers who cannot see it.

MangoMagic names and marks identify the project. The source licence does not
grant permission to imply endorsement by MangoMagic.
